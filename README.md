# Threat Hunt Reports

A collection of threat hunting reports documenting end-to-end security investigations using Microsoft Defender for Endpoint, Microsoft Sentinel, Log Analytics, and KQL.

These reports include:

* Attack timelines
* Investigative evidence and screenshots
* KQL queries used during analysis
* Detection and triage logic
* MITRE ATT&CK mappings
* Incident-response findings
* Containment recommendations
* Confirmed and negative findings used to define incident scope

Each report is structured to show both the technical investigation process and the final security assessment in a clear, evidence-driven format.
